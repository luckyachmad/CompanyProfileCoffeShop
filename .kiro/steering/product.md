# Product Overview

**CompanyProfileCoffeeShop** is a modern branding & digital catalog website (v2.0) for a coffee shop business. It serves as the public-facing digital presence of the brand, integrated with a headless CMS so the shop owner can manage content independently without developer involvement.

## Purpose

- Represent the physical coffeeshop atmosphere (cozy, warm, modern) in digital form
- Attract new customers through dynamic visuals and clear location info
- Enable easy conversion via WhatsApp CTA
- Allow the owner to update menu items and gallery photos in real-time via CMS dashboard

## Target Audience

- **End users**: General public, coffee enthusiasts, potential customers
- **Admin users**: Coffeeshop owner / admin managing content via CMS dashboard

## Page Structure (Single Page Application / Landing Page)

The entire site is a single long-scroll page with 7 main sections:

1. **Hero / Banner** — Full-width background image, headline, sub-headline, CTA button scrolling to Menu section
2. **About Us (Tentang Kami)** — Brand story, philosophy, and unique value proposition with supporting photo
3. **Featured Menu (Menu Unggulan)** — Dynamic from CMS; categorized (Coffee, Non-Coffee, Light Bites); each item shows photo, name, description, price, and Best Seller badge
4. **Gallery (Galeri Foto)** — Dynamic from CMS; aesthetic grid of venue photos with lightbox/modal on click
5. **Testimonials (Testimoni)** — Customer reviews in auto-sliding carousel or card grid
6. **Contact & Location** — Google Maps embed, full address, operating hours, phone, social media links
7. **Footer** — Copyright, quick nav links, logo

## CMS Features (Admin Dashboard)

- Protected login page (email & password)
- Menu management: add/edit/delete items with fields — title, category, description, price, photo, Best Seller toggle
- Gallery management: drag-and-drop photo upload, delete photos

## Out of Scope

- E-commerce (shopping cart, payment gateway, stock management)
- Table reservation / booking system
- Customer account / login system

## Key Integrations

- **WhatsApp CTA**: Floating button (bottom-right, persistent) + per-menu-item button, both with pre-filled message text
- **Google Maps Embed**: Interactive map in Contact section
- **Headless CMS API**: Dynamic data fetching for menu and gallery sections

## Design Theme

Cozy, Warm, Modern & Aesthetic — Earth tones palette (warm coffee brown, cream/beige, charcoal, off-white). Rounded card components, subtle shadows, generous whitespace.
